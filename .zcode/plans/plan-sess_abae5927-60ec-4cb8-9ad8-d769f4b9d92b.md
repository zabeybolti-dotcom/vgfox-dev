## План: Сжатие изображений для ускорения загрузки vgfox.ru

### Что делаем:
1. **Сжать `11.jpg` (21 МБ → ~150-200 КБ)**
   - Конвертировать в WebP с resize до 1920px по широкой стороне
   - Удалить оригинальный `11.jpg`
   - Сохранить как `11.webp`

2. **Сжать `2.jpg` (684 КБ → ~100-150 КБ)**
   - Конвертировать в WebP
   - Удалить оригинальный `2.jpg`
   - Сохранить как `2.webp`

3. **Обновить код в `src/routes/index.tsx`**
   - Строка 5: `import heroBg from "/11.jpg"` → `import heroBg from "/11.webp"`
   - Строка 7: `import brandImg from "/2.jpg"` → `import brandImg from "/2.webp"`

4. **Пересобрать проект**
   - Запустить `npm run build` для обновления `docs/` каталога с оптимизированными файлами

5. **Проверить результат**
   - Убедиться, что файлы уменьшились
   - Визуально проверить через браузер, что качество приемлемое

### Инструменты:
- `sharp` (Node.js) для конвертации и ресайза — быстрый и качественный
- Если `sharp` не установлен, установим как dev-зависимость

### Не затрагиваем:
- `pribor.jpg` (118 КБ) — уже допустимый размер
- External Unsplash изображения (уже оптимизированы через параметры URL)
